자료 구조: 정보를 표현하기 위해 데이터와 이들 데이터간의 상호 관계를 정리하는 것.
데이터를 효율적으로 탐색하고 추가하거나 삭제하는 데 어떻게 데이터
를 저장하거나 연결해야 하는가 다루는 분야.
자료 구조는 데이터 간의 관계를 어떻게 나타낼 것인가에 따라 선형 구조와 비선형 구조로 구분
선형 구조 : 연결 리스트(linked list), 스택(stack), 큐(queue), 데크(dequeue) 등
비선형 구조 : 트리(tree)와 그래프(graph) 등
자료 구조 중에서 선형 구조인 연결 리스트와 스택에 관련된 알고리즘들이 생활 속에서 어떻게
응용되는지에 대해 살펴본다.

게임에서의 리플레이는, 연결 리스트를 활용하는 예시.
Data field/Link field -> Data field/Link field.

찜질방에서 볼수 있는 새 수건더미는 스택의 좋은 예시. 새 수건은 항상 위쪽에 올려놓고, 가져가는 사람들도 가장 위에 있는 수건부터 차례로 가져가는 구조.
스택에 데이터를 저장할 경우 위에서 데이터가 추가되고, 불러올때도 위에서부터 차례로 이루어진다.

배열의 문제는 배열의 크기를 정해야 하는거.
미리 정한 배열 크기보다 적게 사용되면 메모리 낭비이기에 효율적 사용을 위해서는 프로그램 실행에 필요한 만큼의 기억 공간을 확보하는 방법이 필요.(동적 메모리 관리). 동적 할당과 반환필요.
